# VoicePilot AI 🚀

Plataforma SaaS profesional de asistentes telefónicos con Inteligencia Artificial para pequeñas y medianas empresas. Diseñado desde el núcleo como un sistema multiempresa, multisector y de marca blanca.

## 🎯 Objetivo del Proyecto
Construir un "empleado telefónico inteligente" capaz de gestionar llamadas, citas, pedidos y consultas con naturalidad, manteniendo una arquitectura modular, segura y altamente escalable.

## 📂 Estructura del Repositorio

- `ai-engine/`: Motor de IA, control de prompts, WebSockets y pasarela de telefonía.
- `backend/`: API REST central para la gestión del SaaS, usuarios y lógica de negocio.
- `panel/`: Dashboard web (Frontend) para la configuración de clientes sin código.
- `database/`: Migraciones, esquemas y seeders (PostgreSQL).
- `infrastructure/`: Configuración de Docker, contenedores y despliegue.
- `manuals/`: Documentación técnica y para usuarios finales.
- `docs/`: Arquitectura, decisiones (ADRs) y guías de seguridad.

## 🛠️ Tecnologías Principales
- **Backend/Core:** Node.js / TypeScript.
- **Base de Datos:** PostgreSQL.
- **Caché & Estado en Tiempo Real:** Redis.
- **Contenedorización:** Docker.
